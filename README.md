# 华师南海校园开放世界

一个使用 HTML、JavaScript 和 WebGL 开发的第三人称校园探索原型。场景基于华南师范大学佛山校区南海校园的三维沙盘。

## 开始探索

双击 `index.html` 即可在桌面浏览器中离线打开。点击「开始探索」，用 WASD 按镜头方向移动，用鼠标环视，按 Esc 暂停。浏览器未捕获鼠标时，按住左键拖动环视。

角色从教学区南侧主路出发。楼栋外墙会挡住角色，建筑内部暂未开放。按 M 或在暂停菜单中选择「校园地图」可以查看全景与地标。全景视图支持左键旋转、右键平移和滚轮缩放，也可以切换为俯视。

教学楼中轴台阶和侧坡道、图书馆东侧台阶和室外平台、东南门跨水通道都可步行通过。

## 修改游戏

- `src/campus.js` 包含校园边界、道路、楼栋轮廓和地标数据。
- `src/terrain.js` 和 `src/scene.js` 负责地表、三维网格和 WebGL 渲染。
- `src/elevation.js` 定义地形高程、平台、坡道及台阶，供渲染与碰撞共同使用。
- `src/exploration-world.js` 定义角色和镜头的碰撞范围。
- `src/explorer.js` 和 `src/explorer-avatar.js` 负责探索操控、角色动画和小地图。
- `src/viewer.js` 负责全景地图和模式切换。
- `src/index.template.html` 和 `src/campus.css` 定义页面结构和样式。

修改源码后，在仓库根目录运行 `node build.mjs`，重新生成独立的 `index.html`。提交地图改动时一并提交生成后的 HTML。

地形高差、楼高、比例尺和植被位置是近似值。资料出处可在地图的「资料与比例」面板查看。
